Rule of Three Calculator

Quickly solve proportions and rules of three

A is to B as C is to X

X

➗ Formula used

📝 Usage Examples

Speed: If in 2 hours I travel 120 km, how many km will I travel in 5 hours?
A = 2, B = 120, C = 5
X = (120 · 5) / 2
X = 300 km
Price: If 3 products cost $15, how much will 8 products cost?
A = 3, B = 15, C = 8
X = (15 · 8) / 3
X = $40
Recipe: If for 4 people I need 200 g of flour, how much do I need for 7 people?
A = 4, B = 200, C = 7
X = (200 · 7) / 4
X = 350 g
