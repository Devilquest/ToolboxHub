⚙️ How it works

To find a dimension:

New Height = Width · (Aspect Ratio Height / Aspect Ratio Width)

New Width = Height · (Aspect Ratio Width / Aspect Ratio Height)

To find the Aspect Ratio:

GCD = Greatest Common Divisor(Width, Height)

Aspect Ratio = (Width / GCD) : (Height / GCD)

Reference: Wikipedia - Aspect Ratio

📝 Usage Examples

Find Dimension (Height): For a 16:9 ratio, if width is 1920, what is the height?
Aspect Ratio (Width:Height) = 16:9
Width = 1920
Height = 1920 · (9 / 16) = 1080
Find Dimension (Width): For a 4:5 ratio, if height is 1080, what is the width?
Aspect Ratio (Width:Height) = 4:5
Height = 1080
Width = 1080 · (4 / 5) = 864
Find Ratio: An image is 1920px wide and 1080px high. What is its aspect ratio?
Width = 1920
Height = 1080
GCD (1920, 1080) = 120
Ratio = (1920 / 120) : (1080 / 120) = 16:9
