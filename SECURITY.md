# Security Policy

## Supported Versions

We currently support the following versions of ToolboxHub with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within ToolboxHub, please report it privately rather than creating a public issue.

You can report vulnerabilities by:
1. Opening a private vulnerability report if the GitHub project supports it.
2. If not, please contact the lead maintainer [Devilquest](https://github.com/Devilquest) via GitHub or open a placeholder issue requesting a private channel for a security report.

We will acknowledge your report within 1 week and provide a timeline for a fix.

## Security Guidelines

- **Privacy First**: This project is client-side only. We do not transmit your data to any server.
- **Minimal Permissions**: The Content Security Policy (CSP) is strictly configured to prevent unauthorized requests.
- **No External Tracking**: We do not use cookies or tracking scripts.
